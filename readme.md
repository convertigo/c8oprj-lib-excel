


# lib_MicrosoftExcel

This is the Microsoft Excel connector for Convertigo platform. Install this library to enable writing and reading from Microsoft Excel sheets on Office365 Cloud or local XSLX files for your Convertigo applications.

# Dependencies

This library requires the **lib_OAuth** project (declared as a project reference, tag v8.0.1.0). It provides the OAuth login flow used by the Office 365 sequences. When installing from the marketplace, the reference is added automatically; when importing manually, make sure lib_OAuth is present in the workspace.

# Usage for Office 365

The Office 365 sequences call the Microsoft Graph API (`https://graph.microsoft.com/v1.0/me`, connector **MSGraphConnector**). They only work if you performed an OAuth Authentication to AzureAD first. The transactions of **MSGraphConnector** are **Private**: they are called by the sequences of this library (such as [SheetGetRange](#sheetgetrange)), not directly by client applications.

## Configuring your Microsoft Azure AD OAuth

This connector uses the OAuth authentication protocol to exchange data with Microsoft Excel Sheets hosted on Microsoft OneDrive. You must configure OAuth in your Azure portal:

* Connect to https://portal.azure.com/#blade/Microsoft_AAD_IAM/ActiveDirectoryMenuBlade/RegisteredApps
* Click on "new registration"
* Configure **Name** and **Account type**
* Add the http://localhost:18080/convertigo/projects/lib_OAuth/getToken.html redirect URI with the **"Single-page application (SPA)"** type. (Useful for Studio testing operations)
* Add the https://c8ocloud.convertigo.net/convertigo/projects/lib_OAuth/getToken.html with the **"Single-page application (SPA)"** type. (useful for production operations)
* In **Authentication** menu, check **Access tokens (used for implicit flows)** and **ID tokens (used for implicit and hybrid flows)**
* In **API permissions** menu, add Microsoft Graph delegated permissions **Files.Read** (read sheets) and **Files.ReadWrite** (read and write sheets), then grant admin consent if required by your tenant.

Copy and save the **Client ID** and if necessary the **Tenant ID** as you will need these in the next steps.

## Configuring Convertigo Symbols

__lib_MicrosoftExcel__ needs some symbols to be configured. You configure them through the Web Console: **https://<your site>.convertigo.net/admin**, hit the ___symbols___ button to get to the symbol configuration page.


Symbol  | value
------| ------
lib_oauth.azuread.clientid | The **client ID** value you copied in the previous step
lib_oauth.azuread.tenantid | the **tenant id** value you copied in the previous step. This is optional and should be used only if you want to restrict to a specific Azure tenant.
lib_MicrosoftExcel.maxExportCells | Optional. The maximum number of cells of an export made by [ExportDataToSheet](#exportdatatosheet): the fields of all the rows, plus the column names given in its `header` variable. Default is 2000000.

# Usage for local Excel files

To read an Excel file stored on the server and output an XML or JSON structure use the sequence [SheetGetRangeFile](#sheetgetrangefile). It is **Private**: call it from a sequence of your project (for example a sequence that receives the uploaded file and passes its path in `itemPath`), not directly from a client application.

To export data to an Excel output file use the sequence [ExportDataToSheet](#exportdatatosheet). The file is written in the `outputs/` folder of the project, under the name `<random UUID>-<file_name>`. Read its URL from `file/url_path` in the answer. `file/local_path`, the path of the file on the server, is only given to server-side callers (sequences): it is null for an HTTP client.

`file_name` must start with a letter or a digit, contain only letters, digits, `.`, `_` and `-`, not contain `..`, be 80 characters long at most and end with the extension of `book_type` (for example `report.xlsx`). Otherwise the export fails with the error "Invalid output file name". The `html` book type is not supported. The size of an export is limited by the symbol `lib_MicrosoftExcel.maxExportCells` (2000000 cells by default).

# Cleaning generated files

The sequence [clean_outputs](#clean_outputs) deletes the files generated by [ExportDataToSheet](#exportdatatosheet) in the project's `outputs/` folder, and only there (its `target` variable is ignored). It is **Private**: it can be run by a Convertigo scheduled job or called from a sequence, not by an HTTP client. The private sequence [autoRemoveFolder](#autoremovefolder) calls it automatically at startup.

## Sequences

### checkAccessToken

Checks is a valid access token is held by the current users' session for AzureAD

This as to be called by client apps to decide whenever or not they have to display an OAuth login screen

### ExportDataToSheet

Use to export data to various file format (txt, csv, xlsx, ods...). Uses the SheetJS CE framework.

**Output**

<table>
<tr>
<th>name</th><th>comment</th>
</tr>
<tr>
<td>file</td><td>local_path -> Server local file path (internal calls only, null for an HTTP client).<br> url_path -> Server file path url.</td>
</tr>
<tr>
<td>success</td><td>true/false</td>
</tr>
<tr>
<td>error</td><td>Error message.</td>
</tr>
</table>

**variables**

<table>
<tr>
<th>name</th><th>comment</th>
</tr>
<tr>
<td>book_type</td><td>Type of workbook to export to. Default is XLSX. The html type is not supported.</td>
</tr>
<tr>
<td>data</td><td>Data source. Can be a Convertigo Complex variable or a JSON String. It must be an array of objects.</td>
</tr>
<tr>
<td>file_name</td><td>Name of the output file with its extension: it must start with a letter or a digit, contain only letters, digits, dots, underscores and hyphens, be 80 characters long at most and end with the extension of book_type. The file is written under a name made of a random UUID, a hyphen and this name.</td>
</tr>
<tr>
<td>header</td><td>Optional. The order of the columns of the sheet, a JSON array of their names (the keys of the rows of data), written first in this order. Each name counts as a cell of the export.</td>
</tr>
<tr>
<td>sheet_name</td><td>Name of the XLSX Sheet if applicable.</td>
</tr>
</table>

Read a Range of values from an Office 365 Sheet.

**variables**

<table>
<tr>
<th>name</th><th>comment</th>
</tr>

<td>itemPath</td><td>The path of the file to import.</td>
</tr>

### SheetGetRangeFile

Imports an xlsx file ( from "itemPath") and outputs a JSON object of the "name" Sheet by the range of "range". Uses the SheetJS CE framework. **Private**: call it from a sequence, not from a client application.

**variables**

<table>
<tr>
<th>name</th><th>comment</th>
</tr>
<tr>
<td>itemPath</td><td>The local path of the file to import, on the server.</td>
</tr>
<tr>
<td>name</td><td>The sheet name in the workbook (If not provided, the first sheet in a workbook). Can not be empty string.</td>
</tr>
<tr>
<td>range</td><td>The range of cells to retrieve for ex: "A1:D10" (If not provided or empty string, all non empty cells in a sheet)</td>
</tr>
<tr>
<td>options</td><td>Options passed to the SheetJS sheet_to_json call, as a JSON object or a JSON string. For example {"defval":""} fills empty cells with a default value.</td>
</tr>
<tr>
<td>xlsx_read_options</td><td>Options passed to the SheetJS XLSX.read call, as a JSON object or a JSON string. For example {"cellDates":true} reads date cells as real dates instead of serial numbers.</td>
</tr>
</table>

### clean_outputs

Cleans the generated files of the project's `outputs/` folder (for example the files written by ExportDataToSheet). **Private**: it can be run by a Convertigo scheduled job or called from a sequence.

**variables**

<table>
<tr>
<th>name</th><th>comment</th>
</tr>
<tr>
<td>max_time</td><td>Delete only files older than x ms. Default is 86400000ms (24h). Only used when 'all' is 'false'.</td>
</tr>
<tr>
<td>all</td><td>Set value to 'true' to directly delete all files whatever their last modified date. Default is 'false'.</td>
</tr>
<tr>
<td>target</td><td>Ignored: the sequence always cleans the project's outputs/ folder.</td>
</tr>
</table>

### autoRemoveFolder

Private helper sequence, auto-started with the project. It calls clean_outputs on the project's `outputs/` folder to remove generated files older than 10 minutes (600000 ms).

### TestLocalExcelNonRegression

Runs local Excel non-regression checks against versioned XLSX fixtures. Verifies the 50-row sample, typed values, XLSX export, and round-trip import. The temporary round-trip file is deleted before assertions are reported.
